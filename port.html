Internship Work

Four intensive days of building, learning, and shipping real deliverables using AI-assisted workflows.

DAY 01

AI Tool Exploration & Prompt Engineering Basics

Explored the landscape of current AI productivity tools — Claude, ChatGPT, Gemini, Perplexity, and others. Practiced prompt engineering fundamentals: zero-shot, few-shot, chain-of-thought, and role-based prompting. Key insight: prompt quality directly determines output quality.

✦ Deliverable: Prompt Engineering Cheatsheet

DAY 02

Business Automation with AI APIs

Built a mini automation pipeline using the Claude API to process incoming customer queries and generate smart responses. Learned API authentication, JSON handling, and cost-optimisation strategies for LLM usage.

✦ Deliverable: Working automation script + documentation

DAY 03

AI-Assisted Product Research & Competitive Analysis

Used AI tools to research a target market, synthesise competitive intelligence, and produce a structured product brief. Practised using Perplexity for deep research, and Claude for summarisation and formatting.

✦ Deliverable: 10-page Product Research Report

DAY 04

Personal Portfolio Generation (This Site!)

Designed and developed a fully responsive personal portfolio using AI coding assistants. Iterated on design direction, structured content, and deployed a working site that reflects real skills and internship outputs.

✦ Deliverable: Live portfolio · GitHub repo · Reflection note
